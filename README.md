# Vulnerability Assessment & Penetration Test Report

A full VAPT engagement report, written from the consultant's perspective for a simulated client in the resources/mining sector.

## Scope

A black-box vulnerability assessment and penetration test against a simulated client's corporate IT environment, with OT (operational technology) considerations given the client's industrial operations. The engagement covers:

- Terms of engagement and client management
- Reconnaissance and vulnerability assessment findings
- Penetration testing results and risk analysis
- Handling of ethical issues arising during the engagement (legal and reporting considerations)
- Final report and recommendations delivered to the client
